# 🚀 AutoEDA: Automated Exploratory Data Analysis with Mistral and Gradio

## 📝 Description
AutoEDA: An automated solution for Exploratory Data Analysis. Upload your CSV, get instant insights, detailed summaries, and visualizations powered by Mistral LLM and a user-friendly Gradio interface. Streamline your data analysis workflow with AI-driven reports and interactive plots.

## ✨ Features
* **Automated Data Loading**: Seamlessly loads CSV datasets.
* **Intelligent Missing Value Handling**: Automatically imputes missing numerical data with medians and categorical data with modes.
* **Comprehensive Data Summaries**: Generates descriptive statistics for all columns.
* **AI-Powered Insights**: Utilizes the Mistral-7B LLM (via Ollama) to provide insightful textual analysis of your dataset's summary.
* **Automated Visualizations**: Creates essential plots like histograms for numerical distributions and a correlation heatmap for relationships between variables.
* **Interactive Web Interface**: Built with Gradio, offering an easy-to-use drag-and-drop file upload and display of results.

## ⚙️ How It Works
1.  **File Upload**: Users upload a CSV file through the Gradio interface.
2.  **Data Preprocessing**: The uploaded data is read into a Pandas DataFrame, and missing values are handled automatically.
3.  **Analysis & Insight Generation**: Statistical summaries are computed, and these summaries are fed to the Mistral LLM to generate natural language insights.
4.  **Visualization Generation**: Matplotlib and Seaborn are used to create standard EDA plots (histograms, correlation heatmap).
5.  **Report & Display**: All generated text insights and plot images are presented back to the user via the Gradio interface.

## 🛠️ Technologies Used
* **Python**: The core programming language.
* **Gradio**: For creating the interactive web user interface.
* **Pandas**: For data loading, manipulation, and analysis.
* **NumPy**: For numerical operations.
* **Matplotlib**: For creating static, animated, and interactive visualizations.
* **Seaborn**: For making statistical graphics more attractive and informative.
* **Ollama**: For integrating and interacting with local large language models like Mistral-7B.

## 🚀 Setup and Usage

### Prerequisites
* Python 3.x installed.
* Ollama installed and Mistral model downloaded (`ollama pull mistral`).

### Installation
1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/AutoEDA-Automated-Exploratory-Data-Analysis-with-Mistral-and-Gradio.git](https://github.com/your-username/AutoEDA-Automated-Exploratory-Data-Analysis-with-Mistral-and-Gradio.git)
    cd AutoEDA-Automated-Exploratory-Data-Analysis-with-Mistral-and-Gradio
    ```
2.  **Install the required Python packages:**
    ```bash
    pip install -r requirements.txt
    # (Assuming you will create a requirements.txt with: gradio pandas matplotlib seaborn numpy ollama)
    ```
    *Alternatively, install individually:*
    ```bash
    pip install gradio pandas matplotlib seaborn numpy ollama
    ```

### Running the Application
1.  **Ensure Ollama is running and Mistral model is available.**
2.  **Execute the Jupyter Notebook:**
    ```bash
    jupyter notebook "EDA Automation .ipynb"
    ```
    Open the notebook in your web browser and run all cells. This will launch the Gradio application, usually accessible at `http://127.0.0.1:7860/`.
